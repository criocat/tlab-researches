# Исследования рекомендательных систем

Два исследования на KION: автоматизация признаков для CatBoost и RL-дообучение
последовательной GPT-2. Отчёты содержат постановку, результаты и ограничения.

[Установка и данные](docs/ENVIRONMENT.md).
[Все PDF-файлы](docs/PDF_INDEX.md).
[Графики отдельно](figures/).

В репозитории находятся готовые отчёты, графики, код экспериментов
и [результаты выполненных локальных CPU-экспериментов](result_artifacts/).
Сохранённые предложения поиска признаков находятся в `replay/`. Данные загружает
`shared.download`, веса создаются при обучении.

После [установки](docs/ENVIRONMENT.md) основной эксперимент с seed 42 запускается так:

```sh
python reproduce.py task1
python reproduce.py task2
```

Результаты запусков сохраняются в `artifacts/reproduced/`, который игнорируется Git.
`--dry-run` показывает команды без вычислений.

В `result_artifacts/` сохранены результаты уже выполненных локальных запусков:
метрики, выбранные настройки, протоколы, кривые обучения и оценки по пользователям.
Для сравнения нового запуска с сохранённым:

| Поиск выражений | [task1_promptfe/metrics.csv](result_artifacts/task1_promptfe/metrics.csv) | [protocol.json](result_artifacts/task1_promptfe/protocol.json) |

Сводные таблицы: [задание 1](result_artifacts/task1_results.md),
[задание 2](result_artifacts/task2_results.md).
[Окружение исходных запусков](result_artifacts/environment.json).
Файлы скопированы из ранее выполненных CPU-экспериментов; новые обучения при
подготовке этой директории не запускались. Исходный поиск выражений использовал
локальную LLM, а `reproduce.py` повторяет те же предложения через `replay/`.

В основном сравнении первого задания отчёт также содержит средние трёх seed.
В `result_artifacts/task1/` сохранены все три исходных запуска (42, 43, 44);
один запуск с seed 42 воспроизводит соответствующую строку, а не среднее трёх.
Команды полного воспроизведения дополнительных исследований даны отдельно
в инструкциях каждого задания. Один seed сам по себе не гарантирует одинаковую
LLM-генерацию на разных устройствах: для неё предусмотрены сохранённые ответы.

`task1/` и `task2/` содержат модели, признаки и анализ; `shared/` — загрузку,
метрики и анализ; `figures/` — PDF/SVG/PNG графики;
`replay/` — фиксированные выражения
и ответы LLM. Наблюдаемый next-target, sampled ranking и predicted reward
разделены в отчётах: модельный reward не является доказательством удержания.
